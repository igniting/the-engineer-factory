# Source register

Every source used anywhere in the book gets one entry here, with a permanent ID. IDs are never reused or renumbered; a withdrawn source is marked WITHDRAWN with a reason.

**Fields:** ID | Citation (author, title, publisher/venue, year, pages/edition) | Location (URL, DOI, archive, ISBN) | Type (P = primary, S = secondary, D = dataset) | Reliability note (who wrote it, interest, known errors) | Accessed (date; "not yet seen" if located but not opened) | Chapters

**Status codes in the Accessed field:** `seen YYYY-MM-DD` = opened and read in part or full; `located` = existence and bibliographic details confirmed but content not yet read; `unverified` = cited by another source, existence not yet confirmed.
